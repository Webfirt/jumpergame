# Jumper Game

A simple browser platform game inspired by classic key-and-door puzzle gameplay.

The player must move through several levels, collect the key, and reach the exit door to complete the challenge.

## Features

- 3 levels
- keyboard movement and jumping
- key collection system
- door unlock mechanic
- restart and win screens
- simple visual animations and sound effects
